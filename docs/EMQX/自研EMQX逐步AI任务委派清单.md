# 自研 EMQX AI 任务委派清单

## 1. 本版不再让你逐项发指令

**版本：** V3.0 配套，阶段委派简化版，2026-11-13。  
**实施计划：** [自研EMQX分步实施计划.md](./自研EMQX分步实施计划.md)。  
**操作手册：** [自研EMQX分步实施操作手册.md](./自研EMQX分步实施操作手册.md)。

旧版 B01-B40 逐项设计、批准、实现、接受的发送方式不再使用。你只需按 P0-P7 委派，AI 在同包内自行推进 B 批次/子批并记录。技术范围仍完整覆盖 S01-S43，不是删功能或少测试。

**正常用法：** 初始化一次 -> 发 P0 -> 确认基线并发 P1 -> 阶段末简短确认并发下一包。业务缺口、环境越界或生产操作才另外确认。你不需要维护审核表。

下文都是你未来按实际情况发送的模板，不构成当前开工、验收或生产授权。`<...>` 先填真实值；不适用的写明原因；禁止填真实密钥。已确认内容引用即可，不要求重复填写。

## 6. AI 自动维护记录的要求

一份记录足够：当前阶段/任务、技术状态/证据索引、关键决定与授权、下一步/阻塞。详细日志保留在现有测试/CI产物中，不为每个命令生成报告，不要求你签每个子批。

AI 可以写“B14 自检通过”，不能写“用户已审核 B14”，除非你真的说过。阶段通过、业务决定、技术检查和环境授权分开记；未知时间/版本不编造。没有记录位置时在 P0 集中确认一次。
