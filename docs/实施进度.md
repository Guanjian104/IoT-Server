### 入站重放

- 服务连接收到 MQTT 消息后先进入内存队列，写入 MySQL 成功后才确认。
- 数据库不可用时，这条消息留在队列头部，按收到顺序重试。服务连接保持自动重连，不因为这次失败调用 Disconnect。
- 尚未对上命令的回执不挡住后面的上报。它继续留在队列里，不确认。
- 进程退出、服务连接断开，或 Broker 会话因 clean session 被清掉时，尚未确认的消息不会从 Broker 重新投递。
