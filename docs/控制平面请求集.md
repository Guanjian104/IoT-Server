# 控制平面请求集

本地 `iot-dev` 上已经实现的登录、票据、观看和通话接口。设置了 `IOT_SFU_ADDR` 时，观看凭证来自本机 SFU，`provider` 为 `pion`，`connectable` 为 `true`，并带有 `whep_url`。未设置时凭证是 `provider=test`、`connectable=false`。

除登录外，请求带 `Authorization: Bearer <登录返回的 token>` 和 `Content-Type: application/json`。成功正文是下面各接口列出的 JSON。失败正文统一为：

```json
{"error":{"code":"forbidden","message":"forbidden"}}
```

`message` 与 `code` 相同。

| HTTP | code | 含义 |
|---|---|---|
| 400 | `invalid` | 正文无法解析，或通道、流类型、清晰度、客户端、幂等键不合法 |
| 401 | `unauthorized` | 缺少登录令牌，或令牌无效 |
| 403 | `forbidden` | 用户没有该操作所需权限 |
| 403 | `ticket_invalid` | 票据缺失、过期、已换票，或不是这台设备的当前票据 |
| 404 | `not_found` | 设备、会话、观看者或通话不存在 |
| 409 | `conflict` | 设备已禁用或吊销，或当前状态不允许这个动作 |
| 409 | `busy` | 这台设备已有一路未结束的主通话 |
| 409 | `stopping` | 当前流正在停止或停止结果未知 |
| 429 | `rate_limited` | 登录超过每分钟 20 次 |
| 503 | `unavailable` | MySQL、Redis 或依赖调用失败 |

平台管理员绕过设备授权检查。观看和通话仍要提交这台设备的当前票据。

通道 `channel_id` 和流类型 `stream_type` 为 1 到 32 位字母、数字、下划线或连字符。清晰度 `resolution` 可以是空字符串，或者同样的格式。`client_id` 和 `idempotency_key` 为 1 到 64 个字符。

## 登录

`POST /api/v1/auth/login`

```json
{"username":"operator","password":"<口令>"}
```

200：

```json
{"token":"<登录令牌>","expires_at":"2026-11-14T06:00:00Z","user":{"id":2,"username":"operator","tenant_id":"dev","platform_admin":false}}
```

未知用户和错误口令都返回 401。口令只来自环境变量，不写入本文。

## 票据

`POST /api/v1/devices/{deviceId}/tickets`

空 JSON 对象。需要 `ticket` 权限。201：

```json
{"device_id":"94a990cb56a8","version":1,"expires_at":"2026-11-14T06:00:00Z","ticket":"<只返回这一次的票据>"}
```

有效期 12 小时。库里只保存摘要。

`POST /api/v1/devices/{deviceId}/tickets/rotate`

空 JSON 对象。200，正文与创建相同，`version` 加一。没有当前票据时返回 404。

换票后的存量连接留到本轮结束：

- 旧票据不能再创建观看或通话。
- 已经加入的观看者和已经建立的通话保持原状态，直到观看者退出、观看超时、通话进入终态，或会话按既有规则关闭。
- 换票不删除已经发出的媒体凭证，也不因此断开已经加入的成员。

## 观看

`POST /api/v1/devices/{deviceId}/watch`

需要 `view` 权限。`manage` 可以代替 `view`。

```json
{"ticket":"<当前票据>","client_id":"phone","idempotency_key":"w1","channel_id":"1","stream_type":"live","resolution":"sd"}
```

首次 201，同一 `client_id` 加同一 `idempotency_key` 重放为 200：

```json
{
  "session_id":"...",
  "generation":1,
  "session_status":"WAITING_DEVICE",
  "viewer_id":"...",
  "credential":{
    "provider":"pion",
    "connectable":true,
    "token":"<短期凭证>",
    "expires_at":"2026-11-14T06:02:00Z",
    "resource_id":"pion-...",
    "whep_url":"http://127.0.0.1:18090/whep/pion-..."
  }
}
```

持有有效票据但没有查看权限返回 403 `forbidden`。旧票据返回 403 `ticket_invalid`。同一设备的另一个 `client_id` 进入同一个会话。会话在设备和媒体都就绪之前不是 `ACTIVE`。

`POST /api/v1/viewers/{viewerId}/heartbeat`

空 JSON 对象。200：`{"viewer_id":"..."}`。第一次心跳把 `JOINING` 变为 `ACTIVE`。观看者已经 `LEFT` 时返回 409 `conflict`。

`POST /api/v1/viewers/{viewerId}/leave`

空 JSON 对象。200：`{"viewer_id":"..."}`。重复退出仍返回 200，不重复改变占用。

`GET /api/v1/sessions/{sessionId}`

200：

```json
{"session_id":"...","device_id":"94a990cb56a8","status":"ACTIVE","generation":1,"device_ready":true,"media_ready":true,"occupants":1}
```

## 通话

`POST /api/v1/devices/{deviceId}/calls`

需要 `call` 权限。

```json
{"ticket":"<当前票据>","callee":"operator","channel_id":"1","stream_type":"av","resolution":""}
```

201：

```json
{"call_id":"...","session_id":"...","generation":1,"status":"RINGING","device_busy":false}
```

同一设备已有未结束通话时，另一个请求返回 409 `busy`。

`POST /api/v1/calls/{callId}/accept`

空 JSON 对象。接听者必须是另一名持有 `call` 权限的用户。200：`{"call_id":"..."}`。主叫接听返回 403 `forbidden`。只有查看权限的用户返回 403 `forbidden`。

`POST /api/v1/calls/{callId}/reject`

空 JSON 对象。200：`{"call_id":"..."}`。主叫拒绝返回 403 `forbidden`。

`POST /api/v1/calls/{callId}/end`

空 JSON 对象。200：`{"call_id":"..."}`。振铃中由主叫结束记为取消，由被叫结束记为拒绝。已接听或已连接后，主叫或实际接听人可以结束，并释放这路主通话占用。

`GET /api/v1/calls/{callId}`

需要 `view` 或 `call`。200：

```json
{"call_id":"...","device_id":"94a990cb56a8","session_id":"...","status":"CONNECTED","generation":1}
```

通话状态包括 `RINGING`、`ACCEPTED`、`CONNECTED`、`REJECTED`、`TIMEOUT`、`ENDED`、`FAILED`。
